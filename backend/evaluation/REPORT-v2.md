# 衡析扩展真实模型评测报告（v2）

评测日期：2026-09-24（Australia/Melbourne）

## 方法

- 固定题集：30道明确查询、10道口径模糊查询。
- 数据范围：`askdata_mock` 小型企业销售库与 `ecommerce_ops` 电商经营库（约50张业务表）。
- 查询类型：聚合、过滤、Top-N、时间范围、比例、条件聚合、两至四表关联、目标对比。
- 每题使用独立会话，通过项目配置的真实 Qwen、Embedding 和 Rerank 服务运行。
- 明确题同时执行人工标准 SQL；严格比较结果行数、列数和数值。多返回字段、百分数与小数表达差异、主动四舍五入均判为不一致。
- 运行途中因百炼余额不足中断的12题在充值后原题补跑；已经失败的业务题没有重跑或替换。

## 六个严格不一致案例

六题均生成合法 SQL 并执行成功。主要差异为：模型返回百分数而标准答案返回0至1小数、对数值主动保留两位小数、额外返回标识或中间指标字段，以及省略在当前数据中不改变结果的月份过滤条件。优惠券三表关联还存在应使用 `COUNT(DISTINCT ...)` 的潜在重复计数风险。
